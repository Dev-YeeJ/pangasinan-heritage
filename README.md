# Pangasinan Heritage Digital Showcase

## Activity 2: The Pangasinan Heritage Digital Showcase

**Student Name:** Jaime Yee  
**Selected Framework:** Next.js  
**Live Website:** https://Dev-YeeJ.github.io/pangasinan-heritage/

## Description
This project is a digital initiative to promote cultural awareness and tourism for the province of Pangasinan's most iconic heritage sites. It utilizes a modular component library built with Atomic Design principles.

## Features
- **Lightning Fast**: Optimized for fast loading using Next.js Static Site Generation (SSG).
- **Mobile-First**: Fully responsive layouts tailored for mobile, tablet, and desktop viewing.
- **Maintainable**: Built with decoupled, modular Atomic Design components.
- **Accessible**: Strives to follow WCAG 2.1 AA accessibility principles.
- **Deployable**: Deployed using the JAMstack approach on GitHub Pages.

## Local Development
To run this project locally:

1. Install dependencies:
```bash
npm install
```

2. Run the development server:
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) to view it in the browser.

## Deployment (GitHub Pages)
This project is configured to be exported as a static site.
To generate the static files:

1. Run the build command:
```bash
npm run build
```
This will output the static HTML/CSS/JS files into the `out` directory.

2. Deploy the contents of the `out` directory to your GitHub Pages branch (usually `gh-pages`) or configure GitHub Actions to deploy from the `main` branch.
